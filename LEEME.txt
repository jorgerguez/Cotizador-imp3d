Cotiza3D · versión instalable para GitHub Pages
============================================

Repositorio esperado: jorgerguez/Cotizador-imp3d
URL: https://jorgerguez.github.io/Cotizador-imp3d/

1. ANTES DE CAMBIAR ARCHIVOS, abre Cotiza3D y exporta un respaldo JSON desde Ajustes.
2. En GitHub, entra al repositorio y sube los seis archivos de esta carpeta a la RAÍZ de la rama publicada en GitHub Pages.
   - index.html (reemplaza el anterior; conserva la calculadora y agrega configuración PWA)
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - icon-maskable-512.png
3. Confirma que puedes abrir estas rutas:
   https://jorgerguez.github.io/Cotizador-imp3d/manifest.webmanifest
   https://jorgerguez.github.io/Cotizador-imp3d/icon-192.png
   https://jorgerguez.github.io/Cotizador-imp3d/sw.js
4. En Chrome Android, vuelve a cargar la página, espera a que termine de cargar, abre menú ⋮ > Instalar app.
   Si Chrome aún muestra un resultado anterior, cierra la pestaña y entra otra vez, o espera a que se actualice el deploy.
5. Abre la app instalada, comprueba que tus productos siguen ahí y prueba el modo avión DESPUÉS de haberla abierto al menos una vez en línea.

Notas:
- Este paquete no modifica los nombres de las claves de almacenamiento de Cotiza3D.
- La versión HTML individual sigue funcionando como archivo descargado, pero la instalación PWA requiere HTTPS y los demás archivos.
- Instalar no elimina ni sincroniza datos; realiza respaldos JSON periódicamente.
- Cuando cambies de un HTML local (file://) a GitHub Pages (https://), usa Importar respaldo para recuperar tu catálogo.
